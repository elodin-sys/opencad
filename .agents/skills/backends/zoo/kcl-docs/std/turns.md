# std::turns
This module contains a few handy constants for defining turns.
- `turns::HALF_TURN: number(deg) = 180deg`: A half turn, 180 degrees or π radians.
- `turns::QUARTER_TURN: number(deg) = 90deg`: A quarter turn, 90 degrees or π/2 radians.
- `turns::THREE_QUARTER_TURN: number(deg) = 270deg`: Three quarters of a turn, 270 degrees or 1.5*π radians.
- `turns::ZERO: number(Angle)`: No turn, zero degrees/radians.

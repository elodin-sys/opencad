Introduction to Data Files for Interlaboratory Study 2: Blood Pump

  • We are requesting three kinds of files, a single spreadsheet, ASCII text files with numerical results, and image files.  These files consist of:
    • A single spreadsheet with simulation parameters and scalar results for all the specified operating conditions.  This data includes the simulation parameters as well as the resulting pump inlet and outlet pressures, shaft torque, etc.  Give time-averaged results for unsteady simulations.  Optional: Include the absolute and relative computed blood damage index.
    • Results files in ASCII text format, with numeric data along the blade passage plane and the zx outlet plane, for all flow rates and pump speeds.
    • Results files in ASCII text format, with numeric data along the remaining cross-sections and all surfaces, for pump flow rate = 6.0 L/min and pump speed = 3500 rpm only.
    • For unsteady simulations only, a single results file in ASCII text format, with numeric data of time histories of some of the scalar outputs for pump flow rate = 6.0 L/min and pump speed = 3500 rpm only.
    • Images of your mesh.  We are requesting four images of the mesh you used for pump flow rate = 6.0 L/min and pump speed = 3500 rpm.

  • Compress your spreadsheet, data, and image files into one *.zip or *.tar file.  Encrypt your file with a password of your choice.  The *.zip or *.tar file filename should be a unique identifier.  Then upload the zipped file to our server.  Some filename examples:

Potassium_Chloride.zip

Gone_With_The_Wind.zip

Forever_Yours.tar

  • Notify us that your submission is on the ftp server.  In that email, also provide us with the name of your zipped file and the encryption password.  This two part submission process should be sufficient to protect the contents of your file.  We will remove the file from the server as soon as possible.  For blinding during analysis, your name and institution will be stripped out from the file headers and replaced by a code.  The original compressed file will be backed up in case of computer problems.

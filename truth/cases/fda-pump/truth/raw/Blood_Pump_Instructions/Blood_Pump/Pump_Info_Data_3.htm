Cross-Sections

  • This refers to field data defined in the Cross-Sections section.
  • Please provide ASCII data from the blade passage plane and zx outlet plane for all pump flow rates and pump speeds.
  • This data should go into ASCII text files named as follows:

blade_passage_plane_2.5_2500.txt

blade_passage_plane_2.5_3500.txt

blade_passage_plane_4.5_3500.txt

blade_passage_plane_6.0_2500.txt

blade_passage_plane_6.0_3500.txt

blade_passage_plane_7.0_3500.txt

zx_outlet_plane_2.5_2500.txt

zx_outlet_plane_2.5_3500.txt

zx_outlet_plane_4.5_3500.txt

zx_outlet_plane_6.0_2500.txt

zx_outlet_plane_6.0_3500.txt

zx_outlet_plane_7.0_3500.txt

  • Make sure your data is from the solution with the rotor blades at 90º to the outlet.
  • Please provide data formatted as follows:
    • Data names should go on the first line between quotes, so we will know the order in which the data following is given.

Example:

"x"  "y"  "z"  "pressure"  "Velx"  "Vely"  "Velz"  "txy"  "tyz"  "tzx"  "mss"  "vt"

The data need not be in this order, but please make sure the data names are in the same order as the numeric data.

    • Following this, please provide the numeric results from your simulations in text files as lines of numbers formatted like this:

x1  y1  z1  p1  u1  v1  w1  txy1  tyz1  tzx1  mss1  μt1

x2  y2  z2  p2  u2  v2  w2  txy2  tyz2  tzx2  mss2  μt2

x3  y3  z3  p3  u3  v3  w3  txy3  tyz3  tzx3  mss3  μt3

 .

 .

 .

xn  yn  zn  pn  un  vn  wn  txyn  tyzn  tzxn  mssn  μtn

where (xi,yi,zi) are the cartesian coordinates of point i, pi is the pressure at point i, (ui,vi,wi) are the velocity components at point i, (txyi,tyzi,tzxi) are the three components of the viscous shear stress at point i, mssi = mean viscous shear stress at point i, and μti = turbulent viscosity (also known as eddy viscosity) at point i.  If a laminar model was used, then set all μti = 0.  The data may be delimited by spaces or commas, but please add a linefeed/carriage return at the end of each line.  See the Comparison Metrics section for definitions of mean viscous shear stress and turbulent viscosity.

Surfaces

  • This refers to field data defined in the Surfaces section.
  • Please provide ASCII data from the throat, diffuser, rim, outlet fillet, and rotor upper surface for pump flow rate = 6.0 L/min and pump speed = 3500 rpm only.
  • This data should go into files named as follows:

throat.txt

diffuser.txt

rim.txt

outlet_fillet.txt

rotor_upper_surface.txt

  • Make sure your data is from the solution with the rotor blades at 90º to the outlet.
  • Please provide data formatted as follows:
    • Data names should go on the first line between quotes, so we will know the order in which the data following is given.

Example:

"x"  "y"  "z"  "pressure"  "WSS"

The data need not be in this order, but please make sure the data names are in the same order as the numeric data.

    • Following this, please provide the numeric results from your simulations in text files as lines of numbers formatted like this:

                   x1  y1  z1  p1  wss1

                   x2  y2  z2  p2  wss2

                   x3  y3  z3  p3  wss3

                    .

                    .

                    .

                   xn  yn  zn  pn  wssn

where (xi,yi,zi) are the cartesian coordinates of point i, pn = pressure at the wall (N/m2) and wssi = mean viscous shear stress at point i (N/m2).  The data may be delimited by spaces or commas, but please add a linefeed/carriage return at the end of each line.  See the Comparison Metrics section for definitions of mean viscous wall shear stress.

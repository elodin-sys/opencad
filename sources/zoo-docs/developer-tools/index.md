# Zoo Developer Tools

Developer Tools is the umbrella section for the ways you can work with Zoo outside the main product UI. Learn more about our APIs, CLI, SDKs, and tutorials.

## What Lives Here

- [API and SDKs](/docs/developer-tools/api): Use Zoo from your own app, backend, or automation.
- [CLI](/docs/developer-tools/cli/manual): Run Zoo from a terminal or script.
- [MCP](/docs/developer-tools/mcp): Connect Zoo to Claude, Codex, and other MCP-compatible AI tools.
- [Tutorials](/docs/developer-tools/tutorials/beginner-onboarding-js): Follow step-by-step examples for your first integration.

# Errors

Zoo uses conventional HTTP response codes to indicate whether a request succeeded or failed.

| Status | Meaning |
| --- | --- |
| 400 | Error |
| 401 | No valid API key provided. |
| 403 | Error |
| 404 | Error |
| 406 | Error |
| 422 | Error |
| 500 | Error |

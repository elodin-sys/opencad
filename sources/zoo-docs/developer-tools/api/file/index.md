# File

CAD file operations. Create, get, and list CAD file conversions. More endpoints will be added here in the future as we build out transforms, etc on CAD models.

## Endpoints

| Method | Path | Summary |
| --- | --- | --- |
| POST | [/file/center-of-mass](/docs/developer-tools/api/file/get-cad-file-center-of-mass) | Get CAD file center of mass. |
| POST | [/file/conversion](/docs/developer-tools/api/file/convert-cad-file-from-one-format-to-another) | Convert CAD file from one format to another. |
| POST | [/file/conversion/{src_format}/{output_format}](/docs/developer-tools/api/file/convert-cad-file-with-defaults) | Convert CAD file with defaults. |
| POST | [/file/density](/docs/developer-tools/api/file/get-cad-file-density) | Get CAD file density. |
| POST | [/file/mass](/docs/developer-tools/api/file/get-cad-file-mass) | Get CAD file mass. |
| POST | [/file/surface-area](/docs/developer-tools/api/file/get-cad-file-surface-area) | Get CAD file surface area. |
| POST | [/file/volume](/docs/developer-tools/api/file/get-cad-file-volume) | Get CAD file volume. |

# Factory

Operations for submitting and managing Factory manufacturing jobs.

## Endpoints

| Method | Path | Summary |
| --- | --- | --- |
| GET | [/org/factory/jobs](/docs/developer-tools/api/factory/list-factory-jobs-owned-by-your-organization) | List Factory jobs owned by your organization. |
| GET | [/user/factory/finishes](/docs/developer-tools/api/factory/list-finishes-currently-available-for-customer-factory-submissions) | List finishes currently available for customer Factory submissions. |
| GET | [/user/factory/jobs](/docs/developer-tools/api/factory/list-your-personal-factory-jobs) | List your personal Factory jobs. |
| GET | [/user/factory/materials](/docs/developer-tools/api/factory/list-materials-currently-available-for-customer-factory-submissions) | List materials currently available for customer Factory submissions. |

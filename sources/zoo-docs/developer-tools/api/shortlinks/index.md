# Shortlinks

Shortlinks are a way to create a short URL that redirects to a longer URL. This is useful for sharing links that are long and unwieldy.

## Endpoints

| Method | Path | Summary |
| --- | --- | --- |
| GET | [/org/shortlinks](/docs/developer-tools/api/shortlinks/get-the-shortlinks-for-an-org) | Get the shortlinks for an org. |
| GET | [/user/shortlinks](/docs/developer-tools/api/shortlinks/get-the-shortlinks-for-a-user) | Get the shortlinks for a user. |
| POST | [/user/shortlinks](/docs/developer-tools/api/shortlinks/create-a-shortlink-for-a-user) | Create a shortlink for a user. |
| PUT | [/user/shortlinks/{key}](/docs/developer-tools/api/shortlinks/update-a-shortlink-for-a-user) | Update a shortlink for a user. |
| DELETE | [/user/shortlinks/{key}](/docs/developer-tools/api/shortlinks/delete-a-shortlink-for-a-user) | Delete a shortlink for a user. |

# Oauth2

| Method | Path | Summary |
| --- | --- | --- |

| GET | [/org/oauth2/apps](/docs/developer-tools/api/oauth2/list-org-oauth-apps) | List org OAuth apps. |
| POST | [/org/oauth2/apps](/docs/developer-tools/api/oauth2/create-an-org-oauth-app) | Create an org OAuth app. |
| GET | [/org/oauth2/apps/{client_id}](/docs/developer-tools/api/oauth2/get-an-org-oauth-app) | Get an org OAuth app. |
| PUT | [/org/oauth2/apps/{client_id}](/docs/developer-tools/api/oauth2/update-an-org-oauth-app) | Update an org OAuth app. |
| DELETE | [/org/oauth2/apps/{client_id}](/docs/developer-tools/api/oauth2/delete-an-org-oauth-app) | Delete an org OAuth app. |
| GET | [/user/oauth2/apps](/docs/developer-tools/api/oauth2/list-personal-oauth-apps) | List personal OAuth apps. |
| POST | [/user/oauth2/apps](/docs/developer-tools/api/oauth2/create-a-personal-oauth-app) | Create a personal OAuth app. |

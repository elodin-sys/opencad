# API Calls

API calls that have been performed by users can be queried by the API. This is helpful for debugging as well as billing.

## Endpoints

| Method | Path | Summary |
| --- | --- | --- |
| GET | [/async/operations/{id}](/docs/developer-tools/api/api-calls/get-an-async-operation) | Get an async operation. |
| GET | [/org/api-calls](/docs/developer-tools/api/api-calls/list-api-calls-for-your-org) | List API calls for your org. |
| GET | [/org/api-calls/{id}](/docs/developer-tools/api/api-calls/get-an-api-call-for-an-org) | Get an API call for an org. |
| GET | [/user/api-calls](/docs/developer-tools/api/api-calls/list-api-calls-for-your-user) | List API calls for your user. |
| GET | [/user/api-calls/{id}](/docs/developer-tools/api/api-calls/get-an-api-call-for-a-user) | Get an API call for a user. |

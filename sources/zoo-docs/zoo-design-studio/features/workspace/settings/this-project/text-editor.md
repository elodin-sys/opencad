# Text Editor

Configure project-level editor behavior in Zoo Design Studio.

The `Text Editor` section contains project-level editor display preferences.

## Included Settings

### Text Wrapping

Whether to wrap text in the editor or overflow with scroll.

### Blinking Cursor

Whether to make the cursor blink in the editor.

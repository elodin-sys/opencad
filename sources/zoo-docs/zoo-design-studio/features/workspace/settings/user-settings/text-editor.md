# Text Editor

Configure code-editor display behavior in Zoo Design Studio.

Text Editor settings control how KCL is shown and edited in the built-in code editor.

## Included Settings

### Text Wrapping

Enable or disable line wrapping in the code editor.

### Blinking Cursor

Toggle whether the editor cursor blinks.

# Projects

Configure default project creation behavior in Zoo Design Studio.

The `Projects` section contains user-level defaults used when creating new projects.

## Included Settings

### Default Project Name

The default project name to use when creating a new project.

This setting is desktop-only. Project locations are configured under
[User Settings > App](/docs/zoo-design-studio/features/workspace/settings/user-settings/app).

# About Design Studio

View release and update information for Zoo Design Studio.

The `About Design Studio` section gives you version and release information for Zoo Design Studio.

## Available Information and Actions

### App Version

Shows the current app version.

### View Release on GitHub

Open the current release on GitHub.

### Check for Updates

Check whether a newer version of Zoo Design Studio is available.

### Roadmap and Feedback

If you do not see the feature you want, check the roadmap and start a discussion. Feedback here
helps the team prioritize what to build next.

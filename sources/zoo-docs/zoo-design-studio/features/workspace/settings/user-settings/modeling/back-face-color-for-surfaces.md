# Back-Face Color for Surfaces

Display front- and back-face orientation on surfaces in Zoo Design Studio.

Back-face coloring makes surface normal direction visible at a glance. This is useful when inspecting
open surfaces, imported sheet geometry, and downstream surfacing operations that depend on face
orientation.

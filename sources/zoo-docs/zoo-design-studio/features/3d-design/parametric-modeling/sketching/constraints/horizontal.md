# Horizontal

Constrain sketch segments or point pairs to a horizontal relationship in Zoo Design Studio.

The Horizontal constraint keeps selected geometry aligned to the sketch's horizontal direction. Use
it to preserve level edges, centerlines, and reference relationships in a profile.
